# G11 — Knowledge

**Trigger:** Document a decision, maintain canonical guidance, synchronize docs, or capture a lesson.
**Inputs:** Accepted source of truth, audience, decision/evidence links, task-local learning, applicable documentation policy.
**Capability assumptions:** Write access to documentation systems is separate from read access and owner approval.
**Actions:** Identify the canonical location; distinguish facts from proposals; document decisions and rationale; synchronize approved copies; record lessons locally; propose shared changes for owner review and evaluation. For an accepted skill change, follow [skill versioning and release](../skill-versioning-and-release.md).
**Output:** Updated canonical docs or a reviewable documentation proposal, with source links.
**Exit and recovery:** If the canonical location or approval is unclear, draft without replacing existing authority and request the missing decision.
**Authority limit:** An agent must not silently promote task learning into shared instructions, memory, or policy.
