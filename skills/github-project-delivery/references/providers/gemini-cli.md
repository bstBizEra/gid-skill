# Gemini CLI provider notes

The portable entry point is `SKILL.md`. Confirm the current Gemini CLI skill directory, loading behavior, and invocation syntax for the installed version before installation. Requesting a skill by name does not prove it was discovered.

Follow applicable `GEMINI.md` and repository policy. Do not assume another provider's tools, connectors, or authority are available. Context7 and Firecrawl are optional read-only capabilities when configured.
