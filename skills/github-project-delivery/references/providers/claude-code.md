# Claude Code provider notes

The portable entry point is `SKILL.md`. Claude Code has native skill discovery and invocation conventions; confirm its current documentation, project/user scope, and frontmatter requirements before installation. `/github-project-delivery` is an example invocation, not proof of discovery.

Follow applicable `CLAUDE.md` and repository policy. Do not assume Codex tool names or permissions exist in Claude Code. Context7 and Firecrawl are optional capabilities only when configured and available.
